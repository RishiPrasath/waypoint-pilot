# Legacy Materials

This folder stores historical project material used for audit, comparison, and
design work.

Nothing under `legacy/` is approved canonical RAG knowledge. Build tasks and
runtime ingestion code must not ingest this folder directly.

Legacy material can only influence the Phase 2 knowledge base through an
explicit design task that reviews the material and promotes selected content,
metadata, or source lineage into the approved Phase 2 KB structure.

Current legacy inputs:

| Path | Purpose | Status |
|---|---|---|
| `phase1-kb-snapshot/` | Frozen copy of the Phase 1 evaluation KB. | Audit input only |
