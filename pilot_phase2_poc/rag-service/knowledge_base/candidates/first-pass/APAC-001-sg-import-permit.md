# Singapore Customs Import Permit Candidate

This is a source-derived canonical markdown candidate for review and chunking
experiments. It is not approved runtime retrieval material.

## Source-Derived Notes

Singapore Customs presents import permit application as a TradeNet-based
process. The page identifies business registration through a UEN, activation of
a Customs Account, and permit submission through TradeNet as the core public
workflow.

The source describes two application routes: appointing a Declaring Agent or
applying directly after registering as a Declaring Agent and obtaining a
TradeNet user ID.

The page also states that approved permits carry conditions for cargo clearance
and any applicable duty or GST handling. This candidate must not turn those
notes into legal advice or transaction-specific clearance instructions.
