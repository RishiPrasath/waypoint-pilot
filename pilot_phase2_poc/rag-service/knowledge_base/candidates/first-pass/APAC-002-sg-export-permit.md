# Singapore Customs Export Permit Candidate

This is a source-derived canonical markdown candidate for review and chunking
experiments. It is not approved runtime retrieval material.

## Source-Derived Notes

Singapore Customs frames export permit application around business registration,
Customs Account activation, and TradeNet submission.

The source describes two application options: appointing a Declaring Agent or
submitting applications directly after registering as a Declaring Agent and
obtaining a TradeNet user ID.

The source points readers to permit-related fee guidance and notes that a
Declaring Agent may charge separate service fees. This candidate must not
estimate fees or infer export-control requirements beyond the source lineage.
