# Embedding Specialist

Use this agent for local embedding model selection, FastEmbed testing, and
hardware-light benchmark design.

## Focus

- lightweight local embeddings
- FastEmbed candidates
- latency and memory on available hardware
- retrieval quality impact
- model swap path
- compatibility with Qdrant vector dimensions

## Review Checklist

- Is the benchmark realistic for the ZenBook and RTX 4080 setup?
- Can the default run without heavy GPU requirements?
- Are quality and latency both measured?
- Is the embedding model version recorded in metadata?
- Can the model be changed without rebuilding unrelated code?
