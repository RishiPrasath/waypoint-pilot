# Evidence Template

Create the evidence file before opening a PR. Complete it before marking the
task `Complete`.

```markdown
# RAG-$TaskId Evidence

Status: In Progress / In Review / Merged / Complete / Blocked

## Identity

Task:
Branch:
Worktree:
Starting main commit:
PR:
Implementation commit:
Merge commit:

## Artifacts

## Checks Run

## CI And Review

## Issues And Recovery

## Follow-ups
```

Blank fields are not allowed. Use `Pending - reason` before PR or merge, and
`N/A - reason` when a field truly does not apply.
