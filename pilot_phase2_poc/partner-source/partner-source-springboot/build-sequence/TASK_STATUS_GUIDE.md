# Build Sequence Status Guide

Use this build book as the live task tracker for Spring Boot.

## How To Update A Task

When a task starts, set:

- `Status: In Progress`
- `Last Updated` to today's date

When the task is finished and verified, set:

- `Status: Done`
- check off the done criteria
- add a short `Change Notes` block if the implementation drifted from the original draft

If a task is blocked, set:

- `Status: Blocked`
- describe the blocker in one sentence
- leave the original acceptance criteria intact

## What Counts As A Change Note

Add a note when any of these happen:

- the implementation had to move to a different location
- the task needed a small design adjustment
- a command or dependency changed from the draft
- the original wording was too vague and had to be clarified

Keep the note short and factual.
