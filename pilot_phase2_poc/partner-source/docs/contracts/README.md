# Partner Source Local Contracts

This folder contains the local contract sources for the Partner Source implementation lane.

Use these files while building:

```text
openapi/partner-source.v1.yaml
shared-error-contract.md
openapi/http/partner-source-slice1.http
evaluation/contract-test-plan.md
```

The implementation build books, agent personas, and manual runbooks should point here instead of reaching into the older Phase 2 planning workspace.

If a contract changes deliberately, update this folder first, then update `AGREED_SPEC.md`, build-sequence files, tests, and parity checks in the same pass.
